# orangehrm-testing-portfolio
QA Testing Portfolio - OrangeHRM Web Automation Testing

## About
This repository contains QA testing portfolio for OrangeHRM web application, including manual test case and automation testing using Selenium and Java.

## Tools & Technologies
- **Language:** Java
- **Automation:** Selenium WebDriver
- **BDD Framework:** Cucumber
- **IDE:** IntelliJ IDEA
- **Test Management:** Jira
- **Build Tool:** Maven

## Test Coverage
- Authentication (Login)
- Dashbord
- Employee Management (CRUD)

src/
